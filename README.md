# Gate Rush for Android

This repository wraps the Gate Rush web game in a native Android app with [Capacitor](https://capacitorjs.com).
GitHub Actions builds an installable APK on every push to `main`.

## Getting the APK

On your phone, open this repository's **Releases** page (the latest release is at the top) and tap `GateRush-<number>.apk`.
Open the downloaded file and allow "Install unknown apps" when Android asks.

Every build is also attached to its run in the **Actions** tab as **gate-rush-apk** (a zip containing the APK).

Each build has a higher version number, so a new APK installs over the old one and keeps your saves.

## Play on iPhone, iPad or any browser

The same game is published as a web app with GitHub Pages: https://alegandrotah-alt.github.io/gate-rush-android/

On iPhone or iPad, open that link in **Safari**, tap **Share → Add to Home Screen**, then start it from the new icon.
It runs full screen, works offline after the first visit, and keeps saves on the device.
It updates on every push to `main`.

## How the project is organised

The game is plain JavaScript, HTML and CSS with no framework. It's kept as small source files and assembled into one self-contained page.

| Path | What it holds |
|---|---|
| `src/game/*.js` | The game code, split by system (`05-forts.js`, `12-elites.js`, `27-update.js`, `35-render.js`...). Files are joined in name order into one script, so they share one scope. |
| `src/styles/game.css` | All styling |
| `src/page/` | The page markup (`body.html`), title and font links (`meta.html`), and the app wrapper with icons and offline support (`app-head.html`) |
| `src/assets/` | Particle sprites, the sprite atlas and sound effects, embedded into the page at build time |
| `www/gfx3d/` | The pre-rendered 3D sprite sheets, loaded on demand |
| `www/` | The finished app: `index.html` is generated by the build; icons, manifest and offline cache live here |
| `tools/build.js` | Builds `www/index.html` (app) and `dist/gate-rush.html` (bare page) |
| `tools/sim.js` | Balance simulation: seeded bot runs for every ride, no browser needed |
| `tools/browser-check.js` | Loads the game in headless Chromium, plays it, fails on script errors and measures frame times on a slowed CPU |
| `tools/fetch_fonts.py`, `tools/android_setup.py` | Bundle fonts for offline play; set the app icon, splash, portrait lock, full screen and signing |
| `art/` | Launcher icon and splash artwork |

### What happens on every push to `main`

1. **Checks:** build the game, run the balance simulation and the browser check. A crash, a script error or a broken first keep stops the release.
   The run summary shows a balance table and a frame-time figure, and screenshots are attached as **browser-check-screens**.
2. **Android APK:** builds the signed app and publishes it on the Releases page.
3. **Web version:** publishes the game to GitHub Pages.

The `android/` folder and `www/index.html` are generated during the build and are not committed.

## Working on the game locally

Needs Node 20+. For the browser check also run `npm install --no-save playwright && npx playwright install chromium`.

```
npm run build        # assemble www/index.html
npm run sim          # balance simulation (add -- --runs 10 --rides jet,tank for more)
npm run check        # build + quick simulation + browser check
```

Open `www/index.html` through any local web server to play. Add `?debug` to the address to expose test hooks.
In the game, **Settings → Show FPS** shows the live frame rate on a real phone.

To build the Android app yourself you also need JDK 21, the Android SDK and Python with Pillow:

```
npm install
python3 tools/fetch_fonts.py
npm run setup:android
cd android && ./gradlew assembleDebug
```
